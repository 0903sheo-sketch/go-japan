Pola 1: Menjelaskan Isi Suatu Tempat

[Tempat] に [Benda/Orang] が あります / います。

Pola ini berfokus pada Tempatnya. "Di tempat X, ada Y". Ingat gunakan あります (Arimasu) untuk benda mati, dan います (Imasu) untuk benda hidup. Partikel yang digunakan untuk tempat keberadaan adalah に (ni).

部屋へや に ベッド が あります。
Di kamar ada kasur.
庭にわ に 犬いぬ が います。
Di halaman ada anjing.
あそこ に だれ が いますか。
Di sana ada siapa?

Pola 2: Menjelaskan Lokasi Suatu Benda/Orang

[Benda/Orang] は [Tempat] に あります / います。

Pola ini kebalikan dari Pola 1. Fokusnya adalah pada Benda/Orangnya. "Si Y ada di tempat X".

アリさん は 事務所じむしょ に います。
Sdr. Ali ada di kantor.
トイレ は どこ に ありますか。
Toilet ada di mana?

Pola 3: Posisi Lebih Rinci (Atas, Bawah, Dalam, dll)

[Benda Acuan] の [Posisi]

Gabungkan Kata Benda dengan Kata Posisi (Atas, Bawah, Dalam, Luar, dll) menggunakan partikel の (no).

机つくえ の 上うえ に 本ほん が あります。
Di atas meja ada buku.
ポスト は 銀行ぎんこう の 隣となり に あります。
Kotak pos ada di sebelah bank.

Pola 4: Partikel や (Dan lain-lain)

[Benda 1] や [Benda 2]

Jika partikel と (to) digunakan untuk menyebutkan seluruh benda, partikel や (ya) digunakan untuk menyebutkan beberapa contoh saja (A, B, dan lain-lain).

箱はこの 中なか に 手紙てがみ や 写真しゃしん が あります。
Di dalam kotak ada surat dan foto (dan barang lainnya).

トイレは どこに ありますか (Toilet ada di mana?)

アリ (Ali)
すみません。トイレは どこに ありますか。
Permisi. Toilet ada di mana?
店員 (Pelayan Toko)
トイレですか。あそこに あります。
Toilet? Ada di sebelah sana.
アリ (Ali)
ありがとうございます。
あの、じどうはんばいきは ありますか。
Terima kasih.
Anu, apakah ada mesin penjual otomatis (Vending Machine)?
店員 (Pelayan Toko)
はい、じどうはんばいきは トイレの 隣となりに あります。
Ya, mesin penjual otomatis ada di sebelah toilet.
アリ (Ali)
わかりました。ありがとうございます。
Saya mengerti. Terima kasih.
