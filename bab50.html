1. Bahasa Merendah (お + V-masu + します)

Pola ini digunakan saat Anda melakukan sesuatu untuk lawan bicara (atau tindakan Anda melibatkan mereka). Dengan merendahkan tindakan Anda, Anda secara otomatis meninggikan mereka.

私わたし は + お + V-(Coret ます) + します
  • （私わたしが） 重おもい 荷物にもつを お持もちします。
    Saya akan (dengan rendah hati) membawakan barang bawaan yang berat (untuk Anda).
  • 後あとで お電話でんわします。
    Nanti saya akan menelpon (Anda).
  • 明日あしたの 予定よていを お伝つたえします。
    Saya akan menyampaikan jadwal besok (kepada Anda).

2. Bahasa Merendah untuk Gol. 3 (ご + Benda + します)

Khusus untuk kata kerja Golongan 3 yang berasal dari dua huruf Kanji (seperti Annai, Shoukai, Setsumei), awalan yang digunakan adalah ご (go), dan "shimasu" tetap digunakan.

私わたし は + ご + Kata Benda (Gol.3) + します
  • 私わたくしが ご案内あんないします。
    Saya akan memandu (Anda).
  • 社長しゃちょうに 山田やまださんを ご紹介しょうかいします。
    Saya akan memperkenalkan Sdr. Yamada kepada Presiden Direktur.
  • 今日きょうの 結果けっかを ご報告ほうこくします。
    Saya akan melaporkan hasil hari ini.

3. Kata Kerja Merendah Khusus

Gunakan kosakata khusus (dari Tabel 1) saat membicarakan diri Anda sendiri di depan atasan atau pelanggan. Ini sangat sering diucapkan saat wawancara kerja, melayani pelanggan, atau menelepon ke kantor klien.

  • （来きました ➔） インドネシアから 参まいりました。
    Saya datang dari Indonesia.
  • （言いいます ➔） 私わたくしは アリと 申もうします。
    Saya bernama / menyebut diri saya Ali. (Standar perkenalan bisnis).
  • （見みました ➔） はい、その メールは もう 拝見はいけんしました。
    Ya, email tersebut sudah saya lihat/baca.

4. Bahasa Sopan Ekstra (ございます / で ございます)

Gunakan ini sebagai pengganti "arimasu" (untuk benda) dan "desu". Ini tidak merendahkan siapa pun, tetapi hanya meningkatkan nuansa kesopanan dan formalitas (Teineigo) secara umum. Sering dipakai di pengumuman stasiun, pramugari, atau kasir.

  • （あります ➔） お飲のみ物ものは あちらに ございます。
    Untuk minuman ada di sebelah sana.
  • （です ➔） こちらは 東京とうきょうホテルで ございます。
    Ini adalah Tokyo Hotel. (Cara mengangkat telepon di hotel).

Berikut adalah percakapan standar yang sering muncul di Bab 50, khususnya dalam situasi bisnis dan perkenalan formal.

  • A: はじめまして。ABC会社かいしゃの サントスと 申もうします。
    A: Salam kenal. Saya bernama (dari) perusahaan ABC, Santos.
    B: 山田やまだで ございます。どうぞ よろしく お願ねがいいたします。
    B: Saya adalah Yamada. Mohon kerja samanya. (Menggunakan de gozaimasu dan itashimasu).
  • A: その カタログ、拝見はいけんしても よろしいでしょうか。
    A: Apakah tidak apa-apa jika saya melihat katalog itu?
    B: はい、どうぞ ご覧らん ください。
    B: Ya, silakan dilihat. (A merendahkan dirinya dengan haiken, B meninggikan A dengan goran - Bab 49).
  • A: IMCの 松本まつもと部長ぶちょうを 存ぞんじて おりますか。
    A: Apakah Anda mengetahui Manajer Matsumoto dari IMC? (Bertanya menggunakan Kenjougo jika pembicara mewakili perusahaannya/in-group).
    B: はい、存ぞんじて おります。
    B: Ya, saya tahu.
  • A: 重おもそうですね。お持もちしましょうか。
    A: (Barangnya) kelihatan berat ya. Mau saya bawakan?
    B: すみません。お願ねがいします。
    B: Maaf (merepotkan). Tolong (bawakan).
