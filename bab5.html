Pola 1: Menuju Suatu Tempat

[Tempat] へ 行いきます / 来きます / 帰かえります。

Gunakan partikel へ (e) untuk menunjukkan arah atau tujuan pergerakan. Catatan: Meski ditulis dengan huruf hiragana 'he', partikel ini dibaca "e".

私わたしは 京都きょうと へ 行いき ます。
Saya pergi ke Kyoto.
うち へ 帰かえり ます。
Saya pulang ke rumah.

Pola 2: Negasi Total (Tidak pergi kemana-mana)

どこ へも 行いき ません。

Jika tidak pergi kemana-mana, gabungkan kata tanya どこ (Doko/Ke mana) dengan partikel へ (e) + も (mo), diikuti oleh kata kerja bentuk negatif ~ません (~masen).

昨日きのう、どこ へも 行いき ませんでした。
Kemarin, saya tidak pergi kemana-mana (lampau).

Pola 3: Alat Transportasi

[Kendaraan] で [Tempat] へ 行いき ます。

Gunakan partikel で (de) setelah nama kendaraan untuk menunjukkan "dengan/naik".
*Pengecualian: Jika Anda jalan kaki (歩いて/Aruite), tidak perlu memakai partikel で.

電車でんしゃ で 会社かいしゃ へ 行いき ます。
Saya pergi ke kantor naik kereta.
歩あるいて 帰かえり ます。
Saya pulang jalan kaki.

Pola 4: Pergi Bersama Siapa

[Orang/Hewan] と [Tempat] へ 行いき ます。

Partikel と (to) di sini berarti "Bersama dengan".
*Pengecualian: Jika Anda pergi sendirian (一人で/Hitori de), tidak perlu memakai partikel と.

家族かぞく と 日本にほん へ 来き ました。
Saya datang ke Jepang bersama keluarga.
一人ひとりで スーパー へ 行いき ます。
Saya pergi ke supermarket sendirian.
